# Математический бильярд

Песочница для математических бильярдов: один файл `index.html`, без сборки и зависимостей.
Откройте его в браузере на телефоне или компьютере.

- **Столы:** эллипс, круг, прямоугольник, стадион Бунимовича, бильярд Синая, гриб Бунимовича,
  остроугольный треугольник (с орбитой Фаньяно), газ Лоренца, неосвещаемая комната Пенроуза и свой многоугольник.
- **Режим «Луч»:** выберите арену и смотрите, как один светящийся луч отражается от идеальных зеркал,
  а его путь постепенно заполняет комнату. Счётчик отражений в углу; касание стола выпускает новый луч,
  протяжка задаёт направление; скорость — от «Медленно» до «Турбо». Ссылка `index.html#ray` открывает
  сразу этот режим.
- **Запуск:** потяните от точки внутри стола, чтобы задать направление; короткое касание запускает
  шар в случайную сторону. В настройках можно запускать пучок лучей и «близнецов» с крошечной
  разницей угла — на хаотичных столах они быстро расходятся (Δ внизу экрана).
- **Препятствие:** потяните, чтобы поставить круглый рассеиватель; касание по кругу убирает его.
- **Рисовать:** касаниями ставьте вершины своего стола, затем «Замкнуть».
- **Фазы:** фазовый портрет Биркгофа — каждое отражение даёт точку (s, cos φ), где s — длина дуги
  границы, φ — угол между траекторией и касательной.

Физика точная: луч идёт по прямой до пересечения с отрезком, дугой окружности или эллипсом и
зеркально отражается.
