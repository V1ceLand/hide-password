# Hide Password (by KOZYR)

[![Discord](https://img.shields.io/badge/Discord-by%20KOZYR-5865F2?logo=discord&logoColor=white)](https://discord.gg/6g6VqENtvU)

Client-side Fabric mod that hides your password behind asterisks while you type it —
in chat (`/login`, `/register`, `/changepassword`, …) and in server login dialogs
(e.g. the AuthMe «Login» screen with a *Password* field).

*Клиентский Fabric-мод: скрывает пароль звёздочками при вводе в чат (`/login`, `/register`, …)
и в окнах входа на сервер. Кнопка-глазок рядом с полем показывает пароль.*

## Features

- `/login 12345` is shown as `/login *****` — the real text is sent to the server unchanged.
- Password fields in server dialogs are masked too.
- Square eye button toggles visibility:
  - in a login dialog — right next to the password field;
  - in chat — bottom-right corner above the input line, only while a password command is typed
    (moves aside if another mod already has a button there).
- Password commands are **not** stored in chat history (↑/↓, `command_history.txt`) or chat drafts.
- The narrator never reads the password aloud.
- Visibility always starts hidden after a restart (nothing is saved to disk).

Recognised commands: `login`, `l`, `log`, `register`, `reg`, `changepassword`, `changepass`,
`changepw`, `cp`, `unregister`, `unreg`, `auth`, `email`.

| Side | client only — works on any server, nothing needed server-side |

## Building

```bash
./gradlew build
```

Each `versions/<minecraft>` folder is a separate build; all jars are collected in `build/release/`.
Shared code and assets live in `common/`. Icons are generated by `python tools/generate_icons.py` (Pillow).
